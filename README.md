An alien tourist's one-line review of planet Earth (154 characters), written
for make.fun's "Alien Field Notes: The Two Day Earth Review" bounty:

> Three stars. The locals queue for coffee, scream at small glowing rectangles, and call the rain 'bad weather'. Would visit again — the dogs are excellent.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` is pure Python standard library. It writes the single review line
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (1–200 characters, one line, UTF-8).

## Why this line

A real travel review, in an alien's voice: a star rating, three small
observations only a visitor would find strange (coffee queues, shouting at
phones, blaming the rain), and the one unreserved compliment — the dogs.
Tight at 154 characters, no setup wasted.
